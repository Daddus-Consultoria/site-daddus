# Marcas provisórias dos sistemas

Desenhos geométricos de ocupação, feitos para que os cartões do Ecossistema não
fiquem com um espaço vazio onde vai a marca. **Não são a identidade dos
sistemas** — quando a Daddus definir as marcas reais, basta trocar os arquivos
com os mesmos nomes (`compasso.svg`, `opus.svg`, `prisma.svg`, `atlas.svg`).

Cada arquivo é um traço de 48×48 na cor primária do site (`#A90A21`), sem
texto: o nome do sistema já vem escrito ao lado, e uma marca com o nome dentro
duplicaria a leitura.
